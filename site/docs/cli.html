CLI Commands

Zubo provides a comprehensive CLI for managing your agent. All commands are run as zubo <command>.

Core Commands

zubo setup

Interactive setup wizard. Configures API keys, providers, and channels.

zubo setup

zubo start

Start the agent and web dashboard.

# Foreground (default)
zubo start

# Background daemon
zubo start --daemon

zubo stop

Stop the background daemon.

zubo stop

zubo status

Show current configuration and runtime status.

zubo status

Logs

zubo logs

View recent log output.

# Last 50 lines
zubo logs

# Follow logs in real-time
zubo logs --follow

Model Management

zubo model

View or change the active LLM provider and model.

# Show current model
zubo model

# Switch provider/model
zubo model anthropic/claude-sonnet-4-5-20250929
zubo model openai/gpt-4o
zubo model ollama/llama3

# List configured providers
zubo model --list

Skills

zubo skills

Interactive skill management menu.

zubo skills

zubo skills list

List all installed skills with status.

zubo skills list

zubo skills new

Scaffold a new skill with SKILL.md and handler.ts templates.

zubo skills new

zubo install <name>

Install a skill from the community registry.

zubo install weather
zubo install email-summary

zubo search <query>

Search the skill registry.

zubo search "email"
zubo search "calendar"

zubo publish

Publish the current skill to the registry.

# Run from a skill directory
zubo publish

Authentication

zubo auth create-key

Generate a new API key for authenticated access.

zubo auth create-key

zubo auth list-keys

List all active API keys.

zubo auth list-keys

Data Management

zubo export

Export the database as JSON.

zubo export
# Outputs: zubo-export.json

zubo import <path>

Import data from a JSON export.

zubo import ./zubo-export.json
