Getting Started with Zubo

Zubo is a self-hosted AI agent with persistent semantic memory, multi-channel presence, 20+ smart tools, and sub-agent delegation. It runs entirely on your machine — no cloud required.

Features

  • Multi-provider LLM — Claude, OpenAI-compatible, Ollama, with automatic failover
  • Multi-channel — Telegram, Discord, Slack, WhatsApp, Signal, Web Chat
  • Persistent memory — Vector + full-text hybrid search (ONNX embeddings, FTS5)
  • Tool system — Built-in tools, extensible skills, skill registry
  • Integrations — GitHub, Google, Notion, Linear, Jira, Slack, Twitter
  • Workflows — Multi-agent pipelines with delegation
  • Scheduling — Cron jobs, heartbeat, proactive tasks
  • Voice — Speech-to-text (Whisper) and text-to-speech (OpenAI, ElevenLabs)
  • Dashboard — Built-in web UI with analytics, memory management, and settings
  • Document ingestion — Upload PDF, DOCX, TXT, CSV, JSON, and more
  • API authentication — Bearer token auth with key management
  • Skill sandboxing — User-installed skills run in isolated subprocesses

Installation

Zubo requires Bun (v1.0+). Install it in three steps:

Step 1: Install

bun add -g zubo
# or: npm i -g zubo

Step 2: Setup

zubo setup

The interactive setup wizard walks you through:

  • Choosing an LLM provider (Anthropic, OpenAI, Ollama, etc.)
  • Entering your API key
  • Selecting a model
  • Optionally configuring channels (Telegram, Discord, etc.)

Step 3: Start

zubo start

The web dashboard will be available at http://localhost:<port> (shown in terminal output). Use zubo start --daemon to run in the background.

Architecture

User Message → Channel Adapter (Telegram/Discord/Slack/WhatsApp/Signal/WebChat) → Message Router → Agent Loop (LLM + Tool Execution) → Tools (built-in, skills, integrations) → Memory (vector search, FTS5, document parsing) → Scheduler (cron, heartbeat, proactive tasks) → Response → Channel Adapter → User
