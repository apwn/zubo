API Reference

All endpoints are served on the same port as the web dashboard. When auth.enabled is true, all /api/* endpoints require a Authorization: Bearer <key> header.

Chat

POST /api/chat

Send a message and receive a complete response.

// Request
POST /api/chat
Content-Type: application/json

{ "message": "What's the weather in Tokyo?" }

// Response
{ "reply": "The weather in Tokyo is currently 22°C and sunny." }

POST /api/chat/stream

Send a message and receive a streaming SSE response.

// Request
POST /api/chat/stream
Content-Type: application/json

{ "message": "Tell me about Zubo" }

// Response (SSE stream)
event: delta
data: {"text":"Zubo is"}

event: tool
data: {"name":"web_search","status":"start"}

event: tool
data: {"name":"web_search","status":"end"}

event: delta
data: {"text":" a self-hosted AI agent..."}

event: done
data: {"reply":"Zubo is a self-hosted AI agent..."}

POST /api/chat/voice

Send audio for transcription and get a response.

// Request
POST /api/chat/voice
Content-Type: multipart/form-data

audio: (binary audio file)
tts: "true"  // optional

// Response
{
  "transcript": "What's the weather?",
  "reply": "Currently 22°C in your area.",
  "audio": "base64-encoded-audio...",
  "audioFormat": "mp3"
}

File Upload

POST /api/upload

Upload a document for memory indexing. Max 50MB. Supported: PDF, DOCX, TXT, MD, CSV, JSON, HTML, XML, YAML, TS, JS, PY, SH.

// Request
POST /api/upload
Content-Type: multipart/form-data

file: (binary file)

// Response
{
  "uploaded": true,
  "filename": "report.pdf",
  "size": 102400,
  "chunks": 15,
  "wordCount": 4200
}

Dashboard

GET /api/dashboard/status

Agent status overview.

{ "Provider": "anthropic/claude-sonnet-4-5", "Channels": "webchat, telegram", "Messages": "1234", "Memories": "567", "Status": "running" }

GET /api/dashboard/analytics/summary

Usage analytics summary.

{ "totalTokens": 50000, "estimatedCostUsd": 1.23, "avgResponseTimeMs": 450, "sessionCount": 12 }

GET /api/dashboard/analytics/usage-over-time

Token usage by day (last 7 days).

GET /api/dashboard/analytics/tools

Tool usage statistics.

GET /api/dashboard/analytics/sessions

Session breakdown by provider/model.

GET /api/dashboard/analytics/perf-snapshots

System performance snapshots (RSS, heap, DB size) over 7 days.

{ "snapshots": [{ "rss_mb": 120.5, "heap_mb": 85.2, "db_size_mb": 12.3, "created_at": "2026-02-10T12:00:00Z" }] }

GET /api/dashboard/analytics/cost-breakdown

Cost aggregated by provider and model.

{ "breakdown": [{ "provider": "anthropic", "model": "claude-sonnet-4-5", "total_tokens": 50000, "total_cost": 1.23, "requests": 42 }] }

GET /api/dashboard/analytics/response-time-trend

Daily avg/min/max response times over 7 days.

GET /api/dashboard/analytics/top-models

Top 10 models by total tokens.

Memory

GET /api/dashboard/memory

Read MEMORY.md contents.

PUT /api/dashboard/memory

Update MEMORY.md contents. Body: { "content": "..." }

GET /api/dashboard/memory/recent

Last 20 memory chunks.

GET /api/dashboard/memory/search?q=...

Full-text search over memory chunks.

API Keys

POST /api/keys

Create a new API key. Body: { "label": "my-key" }

GET /api/keys

List all API keys.

DELETE /api/keys/:id

Delete an API key by ID.

Rate Limits

When rate limited, endpoints return 429 Too Many Requests with a Retry-After header (seconds). Default limits:

  • Chat: 60 requests/minute per IP
  • Upload: 10 requests/minute per IP
