Channel Setup

Zubo supports six messaging channels. Each channel shares the same memory, personality, and tool access. Configure them in the channels section of ~/.zubo/config.json.

Web Chat

Web Chat is enabled by default and requires no external setup. It provides the built-in dashboard at http://localhost:<port>.

{
  "channels": {
    "webchat": {
      "enabled": true,
      "port": 3000
    }
  }
}

Set port to 0 for an auto-assigned port.

Telegram

  1. Open Telegram and message @BotFather
  2. Send /newbot and follow the prompts to create your bot
  3. Copy the bot token
  4. Add the token to your config:
{
  "channels": {
    "telegram": {
      "enabled": true,
      "botToken": "123456789:ABCdef...",
      "allowedUsers": [12345678]
    }
  }
}

Security: Set allowedUsers to an array of Telegram user IDs to restrict who can talk to your bot. Leave empty to allow anyone.

Discord

  1. Go to the Discord Developer Portal
  2. Click "New Application" and name it
  3. Navigate to Bot → click "Add Bot"
  4. Enable "Message Content Intent" under Privileged Gateway Intents
  5. Copy the bot token
  6. Generate an invite link under OAuth2 → URL Generator (select bot scope with "Send Messages" and "Read Message History" permissions)
  7. Add the token to your config:
{
  "channels": {
    "discord": {
      "enabled": true,
      "botToken": "MTIzNDU2...",
      "allowedUsers": []
    }
  }
}

Slack

  1. Create a new Slack app at api.slack.com/apps
  2. Enable Socket Mode and generate an App-Level Token (xapp-...)
  3. Under OAuth & Permissions, add bot scopes: chat:write, app_mentions:read, im:history
  4. Install the app to your workspace and copy the Bot User OAuth Token (xoxb-...)
  5. Enable Events: subscribe to app_mention and message.im
  6. Add tokens to your config:
{
  "channels": {
    "slack": {
      "enabled": true,
      "botToken": "xoxb-...",
      "appToken": "xapp-...",
      "allowedUsers": []
    }
  }
}

WhatsApp

  1. Add the WhatsApp channel to your config:
{
  "channels": {
    "whatsapp": {
      "enabled": true,
      "allowedNumbers": ["+1234567890"]
    }
  }
}
  1. Start Zubo — a QR code will appear in the terminal
  2. Open WhatsApp on your phone → Linked Devices → Link a Device
  3. Scan the QR code

Note: WhatsApp uses a local session. You'll need to re-authenticate if the session expires.

Signal

  1. Install signal-cli
  2. Register a phone number: signal-cli -u +1234567890 register
  3. Verify with the code sent to you: signal-cli -u +1234567890 verify CODE
  4. Add to your config:
{
  "channels": {
    "signal": {
      "enabled": true,
      "phoneNumber": "+1234567890",
      "signalCliPath": "/usr/local/bin/signal-cli",
      "allowedNumbers": ["+1234567890"]
    }
  }
}

Multiple Channels

You can enable as many channels as you want simultaneously. They all share the same agent, memory, and tools. Disable any channel by setting enabled: false.
