Configuration Reference

Zubo stores its configuration at ~/.zubo/config.json. You can edit it directly or use zubo setup for interactive configuration.

Provider Configuration

Configure one or more LLM providers in the providers object:

{
  "providers": {
    "anthropic": {
      "apiKey": "sk-ant-...",
      "model": "claude-sonnet-4-5-20250929"
    },
    "openai": {
      "apiKey": "sk-...",
      "model": "gpt-4o",
      "baseUrl": "https://api.openai.com/v1"
    },
    "ollama": {
      "model": "llama3",
      "baseUrl": "http://localhost:11434/v1"
    }
  },
  "activeProvider": "anthropic",
  "failover": ["anthropic", "openai", "ollama"]
}

Provider Fields

FieldTypeDescription
apiKeystringAPI key for the provider (optional for Ollama)
baseUrlstringCustom API endpoint URL
modelstringRequired. Model identifier
streamingbooleanEnable streaming responses (default: auto)
contextWindownumberOverride context window size

Channel Configuration

Configure messaging channels in the channels object. See the Channel Setup guide for detailed instructions.

{
  "channels": {
    "webchat": {
      "enabled": true,
      "port": 3000
    },
    "telegram": {
      "enabled": true,
      "botToken": "123456:ABC...",
      "allowedUsers": [12345678]
    },
    "discord": {
      "enabled": true,
      "botToken": "MTIz...",
      "allowedUsers": []
    },
    "slack": {
      "enabled": true,
      "botToken": "xoxb-...",
      "appToken": "xapp-..."
    },
    "whatsapp": {
      "enabled": true,
      "allowedNumbers": ["+1234567890"]
    },
    "signal": {
      "enabled": true,
      "phoneNumber": "+1234567890"
    }
  }
}

Voice Configuration

Configure speech-to-text and text-to-speech providers:

{
  "voice": {
    "stt": {
      "provider": "whisper",
      "apiKey": "sk-...",
      "model": "whisper-1"
    },
    "tts": {
      "provider": "openai",
      "apiKey": "sk-...",
      "voice": "alloy"
    }
  }
}

Agent Settings

FieldTypeDefaultDescription
maxTurnsnumber50Maximum agent loop turns per message
heartbeatMinutesnumber30Background heartbeat interval (1–1440 minutes)

Authentication

Enable API key authentication to protect your endpoints:

{
  "auth": {
    "enabled": true
  }
}

When enabled, all /api/* endpoints require a Authorization: Bearer <key> header. Create keys with zubo auth create-key.

Rate Limiting

FieldTypeDefaultDescription
rateLimit.chatPerMinutenumber60Max chat requests per IP per minute
rateLimit.uploadPerMinutenumber10Max upload requests per IP per minute

Sandbox

User-installed skills run in isolated subprocesses by default:

FieldTypeDefaultDescription
sandbox.enabledbooleantrueEnable skill sandboxing
sandbox.timeoutMsnumber30000Maximum skill execution time in ms

Full Example

{
  "providers": {
    "anthropic": {
      "apiKey": "sk-ant-...",
      "model": "claude-sonnet-4-5-20250929"
    }
  },
  "activeProvider": "anthropic",
  "channels": {
    "webchat": { "enabled": true, "port": 3000 },
    "telegram": { "enabled": true, "botToken": "..." }
  },
  "maxTurns": 50,
  "heartbeatMinutes": 30,
  "auth": { "enabled": false },
  "rateLimit": { "chatPerMinute": 60, "uploadPerMinute": 10 },
  "sandbox": { "enabled": true, "timeoutMs": 30000 }
}
