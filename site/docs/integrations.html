Integrations

Zubo integrates with popular services through built-in skills. Each integration requires a secret (API key or token) that you set through the agent or config.

Setting Secrets

Tell Zubo your secret in chat:

"Set my github_token to ghp_abc123..."

Secrets are stored encrypted in your local database and are never sent to any third party.

GitHub

FieldValue
Secretgithub_token
TypePersonal Access Token (classic)
Scopesrepo, read:user
CapabilitiesIssues, PRs, repos, commits, code search

Setup

  1. Go to GitHub Settings → Tokens
  2. Generate a classic token with repo scope
  3. Tell Zubo: "Set my github_token to ghp_..."

Google

FieldValue
Secretgoogle_api_key
TypeGoogle API Key or OAuth credentials
CapabilitiesGmail, Calendar, Docs, Drive, Sheets

Setup

  1. Go to Google Cloud Console
  2. Create a project and enable Gmail, Calendar, Drive, and Sheets APIs
  3. Create an API key or OAuth 2.0 credentials
  4. Tell Zubo: "Set my google_api_key to AIza..."

Notion

FieldValue
Secretnotion_token
TypeInternal Integration Token
CapabilitiesRead pages, create entries, search databases

Setup

  1. Go to Notion Integrations
  2. Create a new integration
  3. Share the relevant pages/databases with your integration
  4. Tell Zubo: "Set my notion_token to ntn_..."

Linear

FieldValue
Secretlinear_token
TypePersonal API Key
CapabilitiesIssues, projects, sprints, teams

Setup

  1. Go to Linear Settings → API → Personal API Keys
  2. Create a new key
  3. Tell Zubo: "Set my linear_token to lin_api_..."

Jira

FieldValue
Secretjira_token
TypeAPI Token
CapabilitiesIssues, boards, sprints

Setup

  1. Go to Atlassian API Tokens
  2. Create a new API token
  3. Tell Zubo: "Set my jira_token to ..."

Slack (Integration)

FieldValue
Secretslack_token
TypeBot User OAuth Token
CapabilitiesSend messages to channels and users

This is separate from the Slack channel (which receives messages). The integration token lets Zubo send messages proactively.

Twitter / X

FieldValue
Secrettwitter_bearer_token
TypeBearer Token (v2 API)
CapabilitiesPost tweets, read timelines, track mentions

Setup

  1. Apply for a Twitter Developer account
  2. Create a project and app
  3. Generate a Bearer Token
  4. Tell Zubo: "Set my twitter_bearer_token to ..."
