Build

Create your own skill

Skills are self-contained TypeScript modules. Build one in four steps.

1

Scaffold

Run zubo skills new to generate a skill directory with SKILL.md and handler.ts templates.

2

Define

Edit SKILL.md to declare the skill name, description, input schema, and required secrets.

3

Implement

Write your logic in handler.ts. Access inputs, secrets, and return structured results.

4

Publish

Run zubo publish to submit to the skill registry. Others can install with one command.

SKILL.md
# my-skill A brief description of what this skill does. ## Input ```json { "query": { "type": "string", "required": true }, "limit": { "type": "number", "default": 10 } } ``` ## Secrets - `MY_API_KEY` — Required for authentication ## Tags api, search, data
