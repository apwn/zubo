Features

Everything you need.
Nothing you don't.

Zubo combines persistent memory, multi-channel presence, and intelligent tool use into a single, self-hosted AI agent.

Persistent Memory

Zubo remembers your preferences, past conversations, and context across sessions. Powered by vector embeddings stored locally in SQLite.

Multi-Channel

Talk to Zubo on Telegram, Discord, Slack, WhatsApp, or the web. One agent, one memory, everywhere you are.

Smart Tools

Browse the web, search GitHub, manage files, run code, and more. Zubo picks the right tool for each task automatically.

Scheduled Tasks

Set recurring reminders, daily digests, or automated workflows. Zubo runs tasks on schedule even when you're away.

Multi-Provider LLM

Use OpenAI, Anthropic, Google, Groq, Ollama, or any OpenAI-compatible API. Switch providers without changing a line of code.

Sub-Agent Delegation

Zubo can spawn specialized sub-agents for complex tasks like research, coding, or analysis, then synthesize their results.
